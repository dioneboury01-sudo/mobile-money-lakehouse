# Mobile Money Lakehouse Platform

Projet de traitement de données Mobile Money de bout en bout avec architecture Lakehouse (Bronze, Silver, Gold).

## Architecture
- **Ingestion & Processing :** PySpark / Delta Lake
- **Entrepôt Analytique :** PostgreSQL + dbt
- **Orchestration :** Apache Airflow
- **Monitoring & Quality :** Great Expectations / Pydantic
